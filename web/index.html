「珠科百事通」是面向珠海科技学院 3.1 万在校生的校务生活 RAG 智能问答平台。 采集教务处、后勤处、招生办、图书馆 254 篇真实官方通知，经清洗入库后， 通过 FTS5 关键词检索与 bge-m3 语义向量检索双路召回、RRF 融合、bge-reranker 精排、 时效降权，最终由大模型生成带官方出处的回答。

技术栈：Python / FastAPI / SQLite FTS5 / bge-m3 / bge-reranker / 华为云 MaaS LLM
