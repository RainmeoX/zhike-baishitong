| 路径 | 入口 | 用途 |
|---|---|---|
| **AI 开发者空间**（网页版） | https://devstation.developer.huaweicloud.com/ai-devspace | 比赛官方指定入口，浏览器即用；跑官方示例、做项目原型 |

## 二、CodeArts Snap 安装（10 分钟）

1. **VS Code 版本 ≥ 1.72**（低于就先升级 VS Code）
2. `Ctrl+Shift+X` 打开扩展市场 → 搜索 **CodeArts Snap** → 安装华为云官方插件 → 重启 VS Code
3. 登录：右下角弹窗点登录，或左下角 `Huawei Cloud Toolkit: 未登录` → 华为账号扫码/密码验证 → 首次会跳服务开通页，同意协议点"立即开通"（免费）
4. 验证：侧边栏出现 CodeArts Snap 图标（`Alt+R` 打开对话窗口）即为成功

> 常见坑：插件加载不出来先检查 VS Code 版本；公司/校园网代理拦截时在设置里对 Snap 关闭代理。

## 三、核心功能 × 本项目用法（Prompt 直接抄）

| Snap 功能 | 触发方式 | 在珠科百事通里怎么用 |
|---|---|---|
| **注释生成代码** | 写注释后回车 / `Alt+C` | `# 爬取教务处通知列表页,解析标题/日期/链接,输出JSON` → 让它生成 crawler 骨架 |
| **研发问答** | `Alt+R` 开 Chat 直接问 | "SQLite FTS5 中文 trigram 建表语句怎么写" |
| **解释代码** | 选中代码右键 → 解释 | 接手队友代码看不懂时用 |
| **生成单元测试** | 选中函数 → `/test` | 给检索融合函数生成 pytest 用例 |
| **调试排错** | 报错堆栈贴进 Chat | 爬虫被反爬、编码问题时问 |
| **文档生成** | Chat 里让它总结 | 生成 readme/ 的部署说明初稿 |

### 示例 Prompt（冲刺 1 直接抄进 Snap Chat）

```
请帮我写一个 Python 爬虫：爬取 https://jx.zcst.edu.cn 通知列表页的全部通知，
每条提取标题、发布日期、详情页链接，详情页再抓正文纯文本。
要求：请求间隔 5 秒以上、带 UA 和 Referer、输出 JSON 存到 data/raw/、
字段包含 crawl_time。使用 requests + BeautifulSoup。
```

生成后**人工看一遍再采纳**——生成过程截图进 proof，改错的过程也是素材。

## 四、留痕体系（25 分的拿分手册）

### 目录结构（每周一个子文件夹）

```
submission\codearts_proof\
├── week1-冲刺1\
│   ├── 20261002-爬虫Prompt与生成截图.png
│   ├── 20261003-FTS5建表对话.png
│   └── 20261005-爬虫排错过程.md（粘对话+改了什么）
├── week2-冲刺2\
├── week3-冲刺3\
└── week4-提交\
```

### 每天 5 分钟留痕习惯（三件套）

1. **截 Prompt**：问码道的每个关键问题，连同回答截图（重点截"生成代码""排错"）
2. **截结果**：生成的代码采纳后跑起来的效果（终端输出、页面效果）
3. **一句话记录**：这段对话解决了什么问题 → 存进当天文件夹

### 评分对照（确保全覆盖）

评审看"码道在**开发全流程**的覆盖度"，四个环节各至少留 3 条证据：

| 环节 | 留痕内容 |
|---|---|
| 环境搭建 | 开通/登录/初始化项目的截图 |
| 代码生成 | Prompt + 生成结果 + 采纳过程 |
| 调试排错 | 报错贴给码道的对话 + 修复后对比 |
| 文档生成 | 让码道生成 readme/注释/测试的记录 |

### Prompt 质量加分（评审细项"Prompt 设计质量"）

好 Prompt 三要素：**给上下文（什么项目、什么语言）、给约束（间隔 5 秒、输出格式）、给验收（要能跑）**。随手一句"帮我写个爬虫"是拿不到"Prompt 设计质量"分的。
