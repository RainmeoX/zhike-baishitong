## 三、关键设计决策（答辩用）

1. **为什么 LIKE 而不只用 FTS5**：FTS5 默认 unicode61 对中文无效（连续中文当一个 token）、trigram 对 2 字词失效、jieba 增加依赖——LIKE 中文子串 + FTS5 数字/英文的混合方案零新依赖且实测命中。
2. **为什么 199 篇不上 FAISS**：暴力余弦 <10ms，规模决定方案；上 FAISS 是过度工程。
3. **为什么全链路自动降级**：MaaS key 未配置时语义路→关键词路、生成式→抽取式，保证任何环境（评委机器）都能跑起来——工程成熟度优先。
4. **为什么 RRF 融合**：两路分数不可直接比较，RRF 无需调权、公式简单、效果稳定。
5. **为什么重排 + 年份降权**：选课/四六级类通知每年发一份，旧通知高概率误命中——bge-reranker 精排 + 按日期衰减，时效性对齐。

## 四、踩坑记录（已解决）

| 坑 | 解法 |
|---|---|
| 多个 python.exe 进程缓存旧代码，API 返回旧结果 | taskkill 全杀重启，start.py 一键启动根除 |

| Git 凭据选择器弹窗卡死推送 | credential.helper=wincred 全局固定 |
