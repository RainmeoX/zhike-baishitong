# evaluation 评测集（HJQ 主导）

- questions.csv：真实学生问题（目标 100+），列：id、问题、类别、期望答案要点、来源
  - 已建骨架 + 8 条样例（覆盖报修/交通/选课/考试/奖助/转专业/住宿/餐饮）
- 每版系统跑全量回归，准确率目标 ≥ 85%

## 评测运行

```bash
# 启动服务
python -m uvicorn api.main:app --port 8000

# 另开终端跑评测
python -m evaluation.runner --api http://127.0.0.1:8000
```

- 命中判定：期望答案要点中任一关键词出现在答案或参考标题中
- 输出每题命中/未命中 + 准确率

## 类别建议

- 教务-选课 / 教务-考试 / 教务-学籍 / 教务-规章制度
- 后勤-报修 / 后勤-交通 / 后勤-住宿 / 后勤-餐饮
- 招生-奖助 / 招生-政策 / 招生-分数线
