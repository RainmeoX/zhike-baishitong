# 珠科百事通 · 部署说明

> 面向珠海科技学院 3.1 万在校生的校务生活 RAG 智能问答平台。
> 本文档涵盖环境准备、一键部署、手动部署、验证测试的完整流程。

---

## 1. 环境要求

| 项目 | 要求 | 说明 |
|------|------|------|
| 操作系统 | Windows 10/11、Linux、macOS | 需支持 SQLite FTS5 |
| Python | **3.12+** | 推荐 3.12，最低 3.10 |
| pip | 最新版 | `python -m pip install --upgrade pip` |
| 网络 | 可访问硅基流动 / 智谱 API | 国内直连即可，无需代理 |
| 磁盘 | ≥ 200 MB | 含数据库与向量库 |

### 1.1 外部服务（均免费）

| 服务 | 用途 | 注册地址 | 配置变量 |
|------|------|----------|----------|
| 硅基流动 SiliconFlow | embedding (bge-m3) + rerank (bge-reranker-v2-m3) | https://siliconflow.cn | `HWMAAS_API_KEY` |
| 智谱 GLM-4-Flash | 大模型生成回答（永久免费） | https://open.bigmodel.cn | `LLM_API_KEY` |
| Jina AI（可选） | embedding/rerank 备路（海外） | https://jina.ai | `JINA_API_KEY` |

> 硅基流动注册即送额度，bge-m3 / bge-reranker-v2-m3 与华为云 MaaS 同款模型。
> Jina AI 为可选备路，主路（硅基流动）失败时自动 fallback；国内使用需走本地代理。

## 2. 快速部署（一键启动）

### 2.1 克隆代码

```bash
git clone <仓库地址>
cd 华为云码道珠科比赛（RAGGO）
```

### 2.2 配置环境变量

```bash
# 从模板复制
cp .env.example .env
```

编辑 `.env`，填入以下 **3 个必填** 密钥：

```env
# 硅基流动（embedding + rerank）
HWMAAS_API_KEY=sk-你的硅基流动密钥

# 智谱 GLM-4-Flash（LLM 生成）
LLM_API_KEY=你的智谱密钥
```

> 其余变量已在 `.env.example` 中预配好默认值，无需修改。
> Jina AI 备路为可选，不填不影响主流程。

### 2.3 一键启动

```bash
python start.py
```

`start.py` 自动完成以下 4 步：

```
[1/4] 检查 Python 环境
[2/4] 安装依赖（pip install -r requirements.txt）
[3/4] 初始化数据库（首次从 JSONL 入库，已存在则跳过）
[4/4] 启动 API 服务（http://127.0.0.1:8000）
```

启动成功后：

| 地址 | 说明 |
|------|------|
| http://127.0.0.1:8000 | 网页测试台（浏览器直接打开） |
| http://127.0.0.1:8000/health | 健康检查 |
| POST http://127.0.0.1:8000/ask | 问答接口 |

### 2.4 验证

在网页测试台输入问题，如「报修电话是多少」「四六级什么时候报名」，确认返回带出处的回答。

## 3. 手动部署（分步操作）

如需精细控制各环节，可手动执行：

### 3.1 安装依赖

```bash
python -m pip install -r requirements.txt
```

依赖清单：`requests`、`beautifulsoup4`、`lxml`、`fastapi`、`uvicorn`、`pytest`

### 3.2 初始化数据库

```bash
# 从 data/clean/*.jsonl 入库到 data/zcst.db
python -m retrieval.index
```

### 3.3 构建语义向量库

```bash
# 首次构建（286 篇文档批量向量化，约 1-2 分钟）
python -m retrieval.hybrid --rebuild
```

> 此步骤调用硅基流动 bge-m3，需网络连接。若跳过，系统自动退化为纯关键词检索。

### 3.4 启动 API

```bash
python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

### 3.5 跑评测（可选）

```bash
# 40 问评测，目标 ≥85%
python -m evaluation.runner --api http://127.0.0.1:8000 --save
```

## 7. 降级策略

系统设计了多级降级，任何环节失败都能返回可用结果：

| 失败环节 | 降级方式 |
|----------|----------|
| embedding 主路失败 | 自动切 Jina 备路 |
| embedding 两路都失败 | 纯关键词路检索 |
| reranker 失败 | 保持 RRF 排序不变 |
| LLM 未配置/失败 | 抽取式回答（复制最相关句子） |
| 混合检索异常 | 降级为纯关键词检索 |
| 检索无结果 | 返回兜底回答（建议联系部门） |

## 10. 常见问题

### Q1: 启动报错 `embedding 未配置`

`.env` 中 `HWMAAS_API_KEY` 未填或 `.env` 文件不在项目根目录。确认 `.env` 存在且密钥已填入。

### Q2: 语义检索不可用，只有关键词检索

检查硅基流动 API Key 是否有效。系统会自动降级为纯关键词检索，不影响基本功能。

### Q3: LLM 生成未启用，回答是抽取式

`.env` 中 `LLM_API_KEY` 未填。填入智谱 API Key 后重启服务即可。

### Q4: Jina 备路连接超时

Jina AI 为海外服务，国内需走本地代理。在 `.env` 中设置 `JINA_PROXY=http://127.0.0.1:7897`（改为你的代理端口）。无代理可不填 Jina 相关配置，主路（硅基流动）已足够。

### Q5: 数据库需要重建

```bash
# 删除旧库后重新入库
del data\zcst.db        # Windows
rm data/zcst.db         # Linux/Mac
python -m retrieval.index
python -m retrieval.hybrid --rebuild
```
