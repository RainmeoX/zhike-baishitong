# 20261012 业内 RAG 评测标准调研

- **对话内容**：让码道 CodeArts 调研"交付需要什么水平、业内都是怎么做"
- **解决了什么**：调研到 GB/Z 236-2026《检索增强生成系统评价指标与方法》国标（2026-08-27 实施）与业内分层评测惯例——检索（Recall@K/MRR/nDCG）、引用（Citation Precision ≥0.95）、拒答（≥0.95）、答案（事实准确率 ≥0.90/幻觉率 ≤0.10）、运营五层分开测，不混黑盒分；测试集惯例 60% 常规 + 30% 应拒答 + 10% 陷阱题
- **产出结论**：对照本项目差距——缺拒答/陷阱题、引用正确性未校验、答案层指标未单独测；确定冲刺 3 三步优先级：① 100 问按 60/30/10 配比补拒答+陷阱题；② 检索修复建议 1+2 落地（空内容降权 0.8→0.4 + 制度类时效豁免）；③ runner 加引用正确性抽检
