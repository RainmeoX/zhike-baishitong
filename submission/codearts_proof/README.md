# 华为云码道 CodeArts 使用证明 · 总览

> RAGGO!!!!! 队 ｜ 珠科百事通 · 校务生活 RAG 智能问答平台
> 本目录汇总本队在开发全流程中使用华为云码道 CodeArts 的留痕材料，对应评审维度「码道深度使用」（25 分）。

## 一、使用概况

| 维度 | 数据 |
|---|---|
| 码道 AI 会话数 | 8 个独立会话 |
| 使用的模型 | glm-5.3-flash（主力）、GLM-5.2 |
| 提炼的排错/编码经验 | 5 条（S 级 3 条、A 级 2 条）|
| 代码生成会话 | 4 个（爬虫/清洗/配置/启动脚本）|
| 覆盖环节 | 环境搭建、代码生成、调试排错、文档生成 |

## 二、全流程覆盖（对照评审细则）

1. **环境搭建** —— 用码道生成依赖清单、建库脚本、启动脚本（`start.py`/`start-web.cmd`），解决 Git Bash 下 Windows 原生命令的路径转换问题（见排错记录）。
2. **代码生成** —— 爬虫、数据清洗、检索链路、FastAPI 接口、前端门户、微信小程序均由码道生成初稿后人工迭代（见代码生成记录）。
3. **调试排错** —— 5 条排错经验均来自真实踩坑：中文检索失效、爬虫解析陷阱、旧进程缓存旧代码、评测命中判定偏差等（见排错过程记录）。
4. **文档生成** —— 方案书、分工书、README、日志、码道提示词手册均由码道辅助撰写（见 docs/ 目录）。

## 四、Prompt 设计原则

每个任务遵循「Prompt 三要素」：**上下文**（说明项目背景）+ **约束**（字段规范/不引第三方框架/爬虫礼仪）+ **验收**（怎么算完成）。详见 `Prompt记录.md`。
